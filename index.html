Deploy the game

Pushes the game files bundled in this dev site ( files) to the game repo in one commit, then makes sure GitHub Pages is on. Your published tracks.json is never overwritten. The token in the top bar needs Contents: Read and write and Pages: Read and write on the game repo. It stays in this tab's memory only.

Deploy the game server

Pushes the multiplayer server (server.js, package.json, render.yaml, Dockerfile, fly.toml, README) to a GitHub repo using the token in the top bar. If the repo doesn't exist yet it tries to create it (needs a token that can create repos). If you pick the game repo, the server goes in a server/ folder. Then on render.com: New → Blueprint → pick the repo. Every later push here redeploys it automatically.
